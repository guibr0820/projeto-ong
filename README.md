# ONG Esperança

Projeto front-end desenvolvido para representar uma ONG fictícia chamada ONG Esperança.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- DOM
- localStorage
- Git e GitHub

## Estrutura do projeto

projeto/
├── index.html
├── projetos.html
├── cadastro.html
├── css/
│   └── styles.css
├── img/
│   ├── ong-esperanca.jpg
│   ├── projeto-educacao.jpg
│   └── alimentacao-solidaria.jpg
└── js/
    └── script.js

## Funcionalidades

- Navegação entre páginas
- Menu responsivo
- Formulário com validação
- Armazenamento de dados com localStorage
- Feedback visual de sucesso e erro
- Uso de tags semânticas
- Recursos de acessibilidade
- Layout responsivo com Grid e Flexbox

## Acessibilidade

O projeto utiliza tags semânticas como `header`, `nav`, `main`, `section` e `footer`.

Também foram aplicados recursos como:

- atributo `alt` nas imagens
- `aria-label`
- `aria-expanded`
- navegação por teclado
- destaque visual de foco
- contraste adequado entre texto e fundo

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar o Live Server do VS Code.

## Versionamento

O projeto utiliza Git para controle de versão.

A organização considera branches como:

- `main`
- `develop`
- `feature`
- `hotfix`

Os commits seguem mensagens descritivas, por exemplo:

- `feat: adiciona navegação entre páginas`
- `feat: implementa validação do formulário`
- `feat: adiciona persistência com localStorage`
